# Vue UI — implementation plan (plan 2 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the Vue client on a new visual system, bilingual from the start, with every screen finished and every state handled.

**Architecture:** A visual direction is locked first (impeccable direction round), then a token and primitive layer, then screens that consume only the new primitives. Strings live in one JSON catalog per language served by Express and read by a small `useI18n()` composable. Screens call the plan-1 endpoints directly through one `api` module. No component library, no `vue-i18n`.

**Tech Stack:** Vue 3, Vite 6, Pinia, Tailwind 4, vitest (new dev dependency), Express serving `server/web_ui`.

**Spec:** `docs/superpowers/specs/2026-11-17-ui-completion-design.md`

## Global Constraints

- Visual direction comes from the impeccable direction round in Task 1. No screen code before the owner locks a direction; no look may be proposed inside this plan.
- One string catalog per language at `server/public/i18n/en.json` and `vi.json`; both clients fetch it. Missing key falls back to English, then to the key itself. Tests cover both fallbacks.
- Every screen ships loading, empty, error, success and permission states.
- No fake controls: anything visible does something or is removed.
- No new runtime dependency. New dev dependency: `vitest` only.
- API base comes from `server_info.js` (`/` in production, `localhost:3000` in dev).
- Accessibility floor: keyboard reachable, visible focus, labelled inputs, `lang` attribute follows the locale.
- Editor role is not enforced; create/edit visible to any signed-in user, and copy must not claim otherwise.

## Review Focus

1. A missing Vietnamese string must not render `undefined` anywhere — check the fallback chain.
2. Switching language must not lose typed form content or navigation state.
3. Comment and vote states: signed out, own comment, own vote, zero comments, request failure.
4. Search with no matches, empty catalog, and a request that fails must each look intentional.
5. Vietnamese text in fixed-height controls: overflow, wrapping and long names.

### Task 2: String catalog and `useI18n()`

**Files:**
- Create: `server/public/i18n/en.json`, `server/public/i18n/vi.json`
- Create: `web_ui/src/i18n/index.js` (`useI18n`, `loadCatalog`, `setLocale`)
- Modify: `web_ui/src/main.js` (load catalog before mount)
- Modify: `web_ui/src/assets/store/auth_store.js` (locale store or sibling store)
- Test: `web_ui/src/i18n/i18n.test.js`

**Interfaces:**
- Consumes: nothing.
- Produces:
  - `loadCatalog(locale)` → `Promise<object>`; falls back to `en`.
  - `t(key, params?)` → string; missing key returns the English value, then the key.
  - `useI18n()` → `{ locale, setLocale, t }`, locale persisted in a cookie, `<html lang>` updated.

- [ ] **Step 1: Write the failing tests**

```js
test('missing key falls back to English, then to the key', () => {
  const { t } = makeI18n({ en: { greeting: 'Hello' }, vi: {} });
  assert.equal(t('greeting'), 'Hello');
  assert.equal(t('nope.key'), 'nope.key');
});

test('switching locale changes t and the html lang attribute', async () => { /* setLocale('vi') → t('greeting') === 'Xin chào' */ });
```

- [ ] **Step 2: Run and watch them fail**

`cd web_ui && npx vitest run src/i18n` → module not found.

- [ ] **Step 3: Implement the catalog and composable**

`en.json` starts as the full key set for every screen (author it while writing screens; start with shell keys). Keep keys namespaced: `nav.*`, `home.*`, `dish.*`, `ingredient.*`, `auth.*`, `profile.*`, `about.*`, `state.*`, `comment.*`, `vote.*`, `common.*`. No count-dependent plurals; phrase copy to avoid them.

- [ ] **Step 4: Run the tests, then the build**

`npx vitest run src/i18n && npm run build` → pass, built.

- [ ] **Step 5: Commit**

```bash
git add server/public/i18n web_ui/src/i18n web_ui/src/main.js web_ui/package.json web_ui/package-lock.json
git commit -m "feat: shared string catalog and i18n composable"
```
