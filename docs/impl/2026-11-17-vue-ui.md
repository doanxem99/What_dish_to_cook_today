## Files and responsibilities

| Area | Responsibility |
|---|---|
| `web_ui/src/i18n/` | catalog loader, fallback chain, locale persistence, `useI18n()` |
| `server/public/i18n/{en,vi}.json` | the one string catalog both clients read |
| `web_ui/src/api/` | single HTTP module and error mapping |
| `web_ui/src/components/ui/` | primitives built in the locked direction's vocabulary |
| `web_ui/src/views/*` | screens, one per task |
| `web_ui/src/router/index.js` | routes, `/dish_selection` redirect, guarded profile |
| `DESIGN.md` | written at finish from the built system |

## Interfaces

- `loadCatalog(locale)`, `t(key, params?)`, `useI18n()` → `{ locale, setLocale, t }`; fallback EN then key.
- `api.get/post/patch/del` → `Promise<data>`, throws `{status, message}`.
- Primitives: `AppButton variant loading`, `AppInput label error`, `AppCard`, `AppDialog open`, `StateBlock kind`.
- Every API path comes from plan 1's endpoint list; no new endpoints.
