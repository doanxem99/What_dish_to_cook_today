# Adding a dish

Any signed-in cook can add a dish to the catalog. A dish needs at least one ingredient from the
shared catalog, and it becomes public as soon as you save it.

## Before you start

- Sign in. The **New dish** button only appears for signed-in accounts.
- Check the catalog first. If the dish already exists, open it and add your own version as a post
  instead of creating a duplicate.
- Have the ingredient names ready. Every ingredient is picked from the shared catalog, so the board
  can compare dishes fairly.

## Steps

1. Open **Dishes** in the top menu.
2. Select **New dish**.
3. Fill in the English name and the Vietnamese name. The English name must use letters and spaces
   only, because it becomes the catalog key.
4. Add the ingredients. Pick each one from the catalog suggestions; the catalog is shared, so a new
   ingredient is created only when the name is genuinely missing.
5. Set the amount of each ingredient in grams, and set how many servings the amounts make.
6. Choose a cover image. Keep it small; the gallery uses the same folder rules as other uploads.
7. Write the detail blocks. A text block is one step or one note. Write the English text and the
   Vietnamese text in the same block so the two languages stay together.
8. Add servings and nutrition if you know them. These are shown on the dish page and used by the
   assistant when it explains a dish.
9. Select **Save**.

## After saving

- Your dish becomes the best post for the catalog dish until another post earns more votes.
- The public board ranks the dish by how many of your selected ingredients it uses.
- Editing the dish later updates the same post; votes and views stay on the row.
- The assistant index refreshes in the background. A new dish may take a moment to appear in
  answers, but it is always read from the database, never invented.

## Common problems

- **The name already exists.** Open the existing dish and edit your own post instead.
- **The save fails.** Check that every ingredient came from the catalog and that the English name
  uses letters and spaces only.
- **The image does not show.** Use the upload field rather than a path to a file on your computer.
